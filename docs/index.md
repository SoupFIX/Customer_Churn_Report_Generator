## Project Overview

This project automates the typical customer churn analysis workflow:

1. **Data Ingestion & Cleaning** – Load and clean raw data from multiple formats (CSV, Excel, JSON).
2. **Visualization** – Generate a standardized set of exploratory charts (PNG) from the cleaned data.
3. **AI-Powered Chart Analysis** – Use a vision-capable AI model (Google Gemini) to analyze each chart and produce a structured markdown report.
4. **Report Generation** – Convert the markdown report to a polished PDF for sharing.

The target audience includes retail sales, small shops, local shopkeepers, and small vendors who maintain sales records and want to analyze and understand their business churn percentage to improve retention and growth.

## Setup and Installation

### Prerequisites

- Python 3.9+ (tested on 3.10–3.12)
- pip (or preferred package manager)
- A **Google Gemini API key** (free tier available at https://aistudio.google.com/app/apikey)

### Installation Steps

1. Clone the repository (if not already done):
   ```bash
   git clone <repository-url>
   cd customer_churn_analysis
   ```

2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

3. Set up the environment variable for the Gemini API key:
   ```bash
   # Linux/macOS
   export GEMINI_API_KEY="your_google_gemini_api_key_here"

   # Windows (PowerShell)
   $env:GEMINI_API_KEY="your_google_gemini_api_key_here"

   # Or create a .env file in the project root (if using python-dotenv, not currently required)
   ```

   The `ai_model.py` script reads the variable via `os.getenv("GEMINI_API_KEY")`.

## Workflow Overview

The typical end‑to‑end workflow consists of four sequential steps:

1. **Data Ingestion & Cleaning** (`scripts/pipeline.py`)
   - Loads one or more raw files (CSV, Excel, JSON).
   - Cleans column names, removes duplicates, normalizes text, parses dates, fixes data types, handles missing values, and caps outliers.
   - Outputs a cleaned CSV (default: `cleaned.csv` in the project root, or a user‑specified path).

2. **Visualization** (`scripts/visual.py`)
   - Reads the cleaned CSV (default: `cleaned data/cleaned.csv` relative to the script).
   - Auto‑detects a binary target column (e.g., `churn`) or uses a user‑specified target via `--target`.
   - Identifies categorical and numeric features.
   - Generates a standardized set of PNG charts:
     - Target distribution bar chart.
     - Rate‑by‑category horizontal bars for each categorical feature.
     - Distribution histograms & boxplots for each numeric feature.
     - Correlation heatmap (numeric features + target flag).
     - Top‑category interaction bar chart (first two categoricals).
   - Saves charts to a timestamped subfolder under `charts/` (e.g., `charts_2026-07-26_XX/`).

3. **AI‑Powered Chart Analysis** (`scripts/ai_model.py`)
   - Scans the `charts/` directory for the most recently modified subfolder.
   - Encodes each PNG to base64 and sends it to Google’s Gemini vision model (`gemini-3.5-flash-lite`) with a **structured prompt** that ensures consistent, business‑focused analysis.
   - Concatenates each chart’s analysis into a single markdown file (`md files/report_YYYY-MM-DD.md` or a user‑specified path).
   - Includes a summary section with overall positive rate and per‑category rates.

4. **Report Generation** (`scripts/create_pdf.py`)
   - Locates the most recent markdown file in `md files/`.
   - Converts it to a polished PDF using the `markdown-pdf` package.
   - Saves the PDF to `final reports/` with a timestamped filename (e.g., `report_2026-07-26.pdf`).

All steps can be run independently or chained together as needed.

## Detailed Script Descriptions

### pipeline.py

**Purpose:** Robust ingestion and cleaning of heterogeneous data sources.

**Key Features:**

- Supports `.csv`, `.xlsx/.xls`, `.json` (single or multiple files concatenated).
- Automatic column‑name standardization (lowercase, underscore‑separated).
- Duplicate removal, text cleaning (whitespace, placeholder → NaN).
- Date‑column auto‑detect (or user‑specified via `--date-columns`).
- Numeric type conversion from strings with commas.
- Missing‑value handling:
  - Drop columns missing > threshold % (default 50 %).
  - Numeric imputation → median.
  - Categorical imputation → mode (or `"unknown"`).
- Outlier handling via IQR (default) or Z‑score capping (winsorizing).
- Generates a detailed validation report printed to stdout.

**CLI Usage:**

```bash
python scripts/pipeline.py <file1> [file2 ...] \
    [--output cleaned.csv] \
    [--date-columns col1 col2] \
    [--outlier-method iqr|zscore]
```

**Example:**

```bash
python scripts/pipeline.py data/c1.csv data/customer_churn.xlsx -o cleaned.csv
```

**Internal Classes:**

- `DataIngestor`: Handles loading data from multiple file formats.
- `ValidationReport`: Tracks cleaning actions and generates a before/after report.
- `DataCleaner`: Configurable, step‑by‑step cleaning pipeline (each method returns a modified DataFrame).

---

### visual.py

**Purpose:** Produce a consistent, insight‑driven set of exploratory charts for any dataset with a binary target.

**How It Works:**

1. Loads the cleaned CSV (default: `../cleaned data/cleaned.csv` relative to the script).
2. Auto‑detects the target column (binary) using name hints (`churn`, `target`, etc.) or any 2‑unique‑value column.
3. Splits columns into categorical (`≤10` unique values) and numeric (`>10` unique values, excluding ID‑like columns).
4. Generates charts:
   - Target distribution bar chart.
   - Rate‑by‑category horizontal bars for each categorical feature (limited by `--max-category-charts`).
   - Distribution histograms & boxplots for each numeric feature (limited by `--max-numeric-charts`).
   - Correlation heatmap (numeric features + target flag).
   - Top‑category interaction bar chart (first two categoricals).
5. Saves charts to a timestamped folder under `charts/` (e.g., `charts_2026-07-26_XX/`).

**CLI Usage:**

```bash
python scripts/visual.py \
    [--target Churn] \
    [--max-category-charts 6] \
    [--max-numeric-charts 6]
```

**Example:**

```bash
python scripts/visual.py --target churn --max-category-charts 8 --max-numeric-charts 8
```

**Key Functions:**

- `load_file`: Normalizes column names (lowercase, underscores).
- `detect_target_column`: Auto‑detects binary target column.
- `make_target_flag`: Converts any binary column (Yes/No, True/False, 1/0, custom text) to 0/1.
- `detect_categorical_columns`: Identifies categorical columns.
- `detect_numeric_columns`: Identifies numeric columns (excluding ID‑like).
- Chart helper functions (e.g., `chart_target_distribution`, `chart_rate_by_category`, etc.) that create and save PNGs with a consistent style (blue/orange/grey palette).

---

### ai_model.py

**Purpose:** Turn raw chart images into a structured, business‑ready markdown analysis using Google Gemini.

**Process:**

- Scans the `charts/` directory for the most recently modified subfolder.
- Encodes each PNG to base64 and sends it to `gemini-3.5-flash-lite` with a **fixed prompt** that defines:
  - Role: senior data analyst.
  - Context: dataset description (target, feature types).
  - Output schema: title, key insight, statistical note, business implication, recommended action.
- Concatenates each chart’s analysis into a single markdown file (`md files/report_YYYY-MM-DD.md`).
- Includes a summary section with overall positive rate and per‑category rates.

**Requirements:**

- Set environment variable `GEMINI_API_KEY`.
- Install `google-generativeai` (already in `requirements.txt`).

**CLI Usage:**

```bash
python scripts/ai_model.py charts/ [--output md files/report.md]
```

**Example:**

```bash
python scripts/ai_model.py charts/charts_2026-07-26_XX/ -o md files/report_2026-07-26.md
```

**Key Components:**

- `ANALYSIS_PROMPT_TEMPLATE`: Structured prompt ensuring consistent analysis sections.
- `DATASET_CONTEXT`: Provides grounding information about the dataset to reduce hallucinations.
- `encode_image`: Converts PNG to base64 for API transmission.
- `analyze_chart`: Sends a single chart + prompt to Gemini and returns the analysis.
- `analyze_chart_folder`: Loops through all PNGs in a folder, stitches analyses into a report.

---

### create_pdf.py

**Purpose:** Convert the latest markdown report to a PDF for easy sharing/printing.

**How It Works:**

- Uses the `markdown-pdf` package.
- Looks for the most recent `.md` file in `md files/`.
- Outputs a PDF with the same base name (timestamp) into `final reports/`.

**CLI Usage:**

```bash
python scripts/create_pdf.py   # optional --input and --output arguments are supported in the script
```

**Example:**

```bash
python scripts/create_pdf.py --input md files/report_2026-07-26.md --output final reports/churn_report_jul2026.pdf
```

## Example Usage (End-to-End)

```bash
# 1️⃣ Ingest and clean raw data
python scripts/pipeline.py data/c1.csv data/customer_churn.xlsx -o cleaned.csv

# 2️⃣ Generate visualizations (reads cleaned.csv from ../cleaned data/)
python scripts/visual.py
# → creates charts_2026-07-26_XX/

# 3️⃣ Get AI‑driven insights
python scripts/ai_model.py charts/charts_2026-07-26_XX/ -o md files/report_2026-07-26.md

# 4️⃣ Produce a shareable PDF
python scripts/create_pdf.py
# → final reports/report_2026-07-26.pdf
```

After running the above, you will have:

- `cleaned.csv` – tidy dataset ready for modeling.
- `charts/charts_2026-07-26_XX/` – PNG charts covering distributions, rates, correlations, etc.
- `md files/report_2026-07-26.md` – detailed markdown analysis.
- `final reports/report_2026-07-26.pdf` – printable, shareable report.

## Extensibility

- **New file formats:** Extend `DataIngestor.SUPPORTED_EXTENSIONS` in `pipeline.py` and add a loader block in the `load` method.
- **Additional charts:** Add new functions in `visual.py` (e.g., scatter matrix, SHAP values) and call them in `main()`.
- **Alternative LLMs:** Change `MODEL_NAME` and the prompt in `ai_model.py` to use other vision‑capable models (e.g., GPT‑4V, Claude 3).
- **Custom report schema:** Edit the prompt template in `ai_model.py` to include extra sections like risk scores or ROI estimates.
- **Configuration file:** Replace hardcoded thresholds (`--max-category-charts`, outlier method, missing‑value threshold) with a YAML/JSON config.
- **Chart styling:** Modify the color palette and style settings in `visual.py` to match corporate branding.

## Troubleshooting

| Symptom | Likely Cause | Fix |
|---------|--------------|-----|
| `ModuleNotFoundError: No module named 'google-generativeai'` | Missing dependency | Run `pip install google-generativeai` |
| `FileNotFoundError` for `cleaned.csv` | `visual.py` run before `pipeline.py` or wrong path | Run `pipeline.py` first or edit `visual.py`’s `load_file` call to point to the correct location. |
| API key error | `GEMINI_API_KEY` not set | Export the variable or create a `.env` file. |
| No charts generated | Target column not detected | Use `--target <column_name>` to specify the binary column explicitly. |
| PDF generation fails | Missing `pandoc` or `wkhtmltopdf` (backend of `markdown-pdf`) | Install required system dependencies (`brew install pandoc` / `apt-get install pandoc`). |
| Outlier handling removes too many rows | Threshold too strict for small datasets | Adjust `--outlier-method` or change the IQR multiplier by editing `handle_outliers` in `pipeline.py`. |
| Charts look cluttered | Too many categories/numeric columns | Reduce `--max-category-charts` or `--max-numeric-charts`. |
