## Project Overview

This project is a customer churn analysis workflow consisting of three main scripts:

1. `scripts/pipeline.py` - Data ingestion and cleaning pipeline
2. `scripts/visual.py` - Chart generation and visualization
3. `scripts/ai_model.py` - AI-powered chart analysis using Google Gemini

The workflow is:
1. Use `pipeline.py` to ingest and clean raw data (CSV, Excel, JSON) into a cleaned CSV.
2. Use `visual.py` to generate charts from the cleaned data and save them to the `charts/` directory.
3. Use `ai_model.py` to analyze the generated charts and produce a markdown report.

## Setup

1. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

2. Ensure you have a Google Gemini API key set up for the AI model (see `ai_model.py` for details).

## Common Commands

### Run the data pipeline
To ingest and clean data from one or more files:
```bash
python scripts/pipeline.py <file1> [file2 ...] --output cleaned.csv
```
Options:
- `--output`: Output CSV file path (default: cleaned.csv)
- `--date-columns`: Explicit column names to parse as dates (optional)
- `--outlier-method`: Outlier handling method (`iqr` or `zscore`, default: iqr)

Example:
```bash
python scripts/pipeline.py data/customers.csv data/january.xlsx --output cleaned.csv
```

### Generate visualizations
To generate charts from the cleaned data:
```bash
python scripts/visual.py
```
This script expects `cleaned.csv` in the root directory and saves charts to the `charts/` directory.

### Analyze charts with AI
To analyze the generated charts and produce a markdown report:
```bash
python scripts/ai_model.py charts/ --output chart_analysis_report.md
```
Options:
- `--output`: Path to save the markdown report (default: chart_analysis_report.md)

## Workflow Example

1. Clean the data:`
   ```bash
   python scripts/pipeline.py data/raw_data.csv -o cleaned.csv
   ```

2. Generate charts:
   ```bash
   python scripts/visual.py
   ```

3. Analyze charts:
   ```bash
   python scripts/ai_model.py charts/ -o churn_analysis_report.md
   ```

## Project Structure

- `scripts/`: Contains the three main Python scripts.
- `charts/`: Directory where visualizations are saved (generated by `visual.py`).
- `cleaned.csv`: The cleaned dataset (generated by `pipeline.py`).
- `requirements.txt`: Python dependencies.

## Notes

- The `visual.py` script expects a column named `churn` with values 'Yes' or 'No' to create the churn flag.
- The `ai_model.py` script requires a Google Gemini API key. Set the environment variable `GEMINI_API_KEY` (see setup instructions in the script).
- The `charts/` directory is created automatically by `visual.py` if it doesn't exist.
- For PDF report generation, use `scripts/create_pdf.py` which converts `report1.md` to PDF and saves it in `reports/`.
